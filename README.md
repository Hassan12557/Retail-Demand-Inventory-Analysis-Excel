Retail Sales Analytics Dashboard

This project focuses on analyzing retail transactional data to derive actionable business insights related to sales performance, customer behavior, and operational efficiency.

🎯 Project Objective

To transform raw retail data into an interactive Excel dashboard that enables business stakeholders to monitor key performance metrics and make data-driven decisions.

🛠 Tools & Technologies Used

Microsoft Excel

Power Query

Pivot Tables

Data Visualization Techniques

📈 Key Features

Data cleaning and transformation pipeline

KPI design for business performance monitoring

Customer segmentation analysis

Product category performance insights

Interactive dashboard with slicers

📊 Dashboard Insights

The dashboard provides insights into:

Monthly sales trends

Revenue by customer segment

Product category performance

Geographic sales distribution

Payment and shipping behavior
